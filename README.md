# OTT Streaming Content Trend Analysis

## Project Overview
This project analyzes Netflix Movies and TV Shows data to understand content trends and patterns.

## Dataset
Netflix Movies and TV Shows dataset containing 8,807 records and 12 columns.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- SQL
- Google Colab

## Work Completed
- Loaded and explored the Netflix dataset.
- Handled missing values.
- Analyzed Movies and TV Shows.
- Identified the top 10 genres and countries.
- Analyzed content ratings and movie durations.
- Created six visualizations.
- Performed data aggregation using five SQL queries.
- Prepared a Content Strategy Memo with three key insights and recommendations.

## Key Findings
- Movies: 6,131
- TV Shows: 2,676
- Top genre label: International Movies
- Leading country: United States
- Most common rating: TV-MA

## Project Files
1. OTT_Streaming_Content_Trend_Analysis.ipynb
2. Netflix_SQL_Queries.sql
3. Netflix_Content_Strategy_Memo.pdf

## Conclusion
This project helped identify Netflix content trends using Python, data visualization, and SQL. The findings provide useful insights for content planning and strategy.
